### 🚀 Featured Project

#### AWSSBG-CDM Website
**Official Website of the AWS Student Builder Group – Colegio de Muntinlupa**

A cloud-hosted organizational website designed to centralize community information, showcase events, manage officers, and support administrative operations.

**Key Features & Implementations:**
- Public-facing website for organizational information and events.
- Administrative dashboard with Amazon Cognito authentication.
- Event management with draft and publish workflows.
- Serverless backend using AWS Lambda and API Gateway.
- Amazon DynamoDB integration for application data.
- GitHub-integrated deployment through AWS Amplify.
- Custom domain and SSL configuration.

**Technologies:** JavaScript, HTML, CSS, Node.js, AWS Amplify, Amazon Cognito, AWS Lambda, Amazon API Gateway, Amazon DynamoDB, AWS IAM, and Amazon CloudWatch.
